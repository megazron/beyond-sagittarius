# Security

Beyond Sagittarius is a single-player game with no accounts, no server and no network features in the Android app.
If you still find a security problem (for example in the web build, the desktop app or the Android app), please
report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**.
Please do not open a public issue for it.

I read every report and reply in the advisory thread.
